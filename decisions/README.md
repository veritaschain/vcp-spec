# Decision records

This directory holds the authoritative records of decisions on normative VCP artifacts, under [VCP-PROC-001](../CHANGE-CONTROL.md).

- [REGISTER.md](REGISTER.md) lists every change proposal with its class and status.
- [TEMPLATE.md](TEMPLATE.md) is the template for new decision records.
- `VCP-DR-YYYY-NNN.md` files are individual decisions.

A change is **adopted** only when its decision record, with decision Accepted or Accepted with changes, is merged here. Merging a proposal document, a passing CI run or the absence of objections is not adoption.
